# iF/elsE

Desenvolvi uma composição generativa em p5.js que explora três estruturas condicionais para criar variações visuais dinâmicas. O programa divide o espaço do ecrã em quadrantes sensíveis à posição do cursor: o eixo horizontal altera o ambiente cromático do fundo entre claro e escuro, o eixo vertical modifica a paleta de cores dos elementos da grelha, e a proximidade do rato ajusta a escala das formas. Adicionalmente, a composição responde a comandos de teclado, permitindo alternar instantaneamente a geometria visual de círculos para quadrados.
